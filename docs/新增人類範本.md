# 新增人類範本

照下面的格式寫，一隻一段，貼給 Claude 就好。**不知道的欄位留空**，Claude 會幫你補。
寫越完整，Claude 要想的越少，用量就越省。

```
名字：泛舟哥
屬性：水（火／水／土／風）
出處：新聞人物
個性：普通／強壯／很快／很硬（決定數值，也可以留空）
招式1：颱風天就是要泛舟｜攻擊
招式2：大聲說出來｜降低對手攻擊
（招式效果可以寫：攻擊、強力攻擊、連續攻擊、一定先出手、回血、
  提升自己攻擊／防禦、降低對手攻擊／防禦／命中、讓對手睡著、讓對手燒傷）
圖鑑：颱風天堅持要泛舟，肺活量驚人，肉質吸飽了雨水。產地：颱風天的街頭。
出場台詞：野生的泛舟哥出現了！「颱風天就是要泛舟啊！」
收服台詞：收服成功！泛舟哥｜肉質：{grade}｜備註：含水量偏高，下鍋前請瀝乾。
掙脫台詞：泛舟哥大吼一聲，把寶貝球震開了！
宿敵（可留空）：遇到 牛／豬／羊／雞 時說：……
出現地點（可留空）：廣場／大廳／月台
```
