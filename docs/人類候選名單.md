# 野生人類候選名單（草稿，給你挑）

目標 51 隻，這份列了 80 個候選讓你挑。打 ✅ 的是目前遊戲裡已經有的。

**第二批已選（已經做進遊戲）：** 火：赤犬、煉獄杏壽郎、小智、中式料理廚師、乩童｜水：青雉、釣客、泛舟哥、水行俠、救生員｜土：牛魔王、肯德雞爺爺、綠巨人浩克、兩津勘吉、我愛羅｜風：麥當勞叔叔、蝙蝠俠、山道猴子、服部半藏

（小智、泛舟哥、肯德雞爺爺、兩津勘吉、麥當勞叔叔、蝙蝠俠、山道猴子、服部半藏是使用者另外加的，不在原本名單上。）

**屬性的意思（設計文件第四節）：**
- **火**：熱血、衝動、爆發力、跟火有關
- **土**：堅硬、死板、重量、實體資產、跟土地岩石有關
- **風**：嘴砲、速度、資訊、網路、跟天空空氣有關
- **水**：冷靜、摸魚、冷暴力、跟水有關

相剋：火 → 土 → 風 → 水 → 火（衝動打碎死板、實體資產壓制嘴砲、資訊轟炸戳破摸魚、冷暴力熄滅怒火）

> 只給朋友玩，所以可以用真實人物和作品角色。真實人物的梗只拿他們公開的形象開玩笑。

## 挑選建議

1. **每個屬性先挑 3～4 隻**放在台北車站附近，讓玩家一開始就會遇到屬性相剋的狀況。
2. **同一部作品的角色可以湊成一組**，之後做「進化」或「道館主題」：
   - 西遊記一家：孫悟空、豬八戒、沙悟淨、唐三藏、牛魔王、紅孩兒、鐵扇公主
   - 驚奇四超人：石頭人、霹靂火
   - 海賊王海軍三大將：赤犬（火）、青雉（水）、黃猿（風）
   - 鬼滅之刃：煉獄（火）、伊之助（土）、義勇（水）、炭治郎（水）
3. **跟主角有關的梗**：牛魔王遇到牛、豬八戒遇到豬，可以有專屬台詞。
4. **真實人物**在遊戲裡的台詞、圖鑑也只拿公開形象開玩笑，避免牽扯私生活。
